## Support

Thank you for using **Bricks Backend**. This document explains how to get help and where to ask questions.

---

## Questions & Usage Help

For general questions about:

- Setting up Bricks Backend locally
- Configuring environment variables
- Integrating with the Bricks frontend

please:

- First check the `README.md`, `CONTRIBUTING.md`, and `SECURITY.md`.
- Then use your usual internal communication channels (e.g. Slack/Teams/email) if you are part of the core team.

---

## Bug Reports & Feature Requests

- Use **GitHub Issues** and select:
  - **“Bug report”** for defects or regressions.
  - **“Feature request”** for enhancements or new capabilities.
- Please follow the respective issue template so we can triage and respond efficiently.

---

## Security Issues

If you believe you have found a **security vulnerability**, **do not** open a public issue.

Instead, follow the instructions in `SECURITY.md` and contact:

- **Email**: `rjsharmase@gmail.com`
